# 数据来源

- 提供方：Nevada Geodetic Laboratory（NGL），University of Nevada, Reno。
- 测站：ALBH。
- 产品：IGS20 参考框架下的每日最终解，tenv3 格式。
- 测站页面：https://geodesy.unr.edu/NGLStationPages/stations/ALBH.sta
- 下载地址：https://geodesy.unr.edu/gps_timeseries/IGS20/tenv3/IGS20/ALBH.tenv3
- 格式说明：https://geodesy.unr.edu/gps_timeseries/readmes/README_tenv3.txt

本地快照包含 11,891 条记录，覆盖 1994-01-02 至 2026-10-03。数据产品可能继续更新；本文件记录的是项目当前保存的快照。

原始数据保存于 `raw/ALBH.tenv3`。数据权益归原提供方，使用、引用和发表时请遵循测站页面的数据来源及引用要求，包括 NGL 提示的 Blewitt et al. (2018) 和原始数据来源引用。
