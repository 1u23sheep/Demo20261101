# GNSS 时间序列入门项目

使用 NGL 公开 GNSS 每日坐标时间序列，逐步学习 Python 数据读取、位移绘图与趋势分析。

## 当前进度

- 定位原始数据文件并检查是否存在。
- 读取表头和第一条观测记录。
- 拆分字段，提取测站名称与日期。

后续计划：单位转换、E/N/U 相对位移绘图、数据质量检查与最小二乘拟合。

## 运行

需要 Python 3；当前代码只使用标准库，无需安装额外依赖。

```bash
python3 main.py
```

## 文件

- `main.py`：逐步编写的学习代码。
- `data/raw/ALBH.tenv3`：下载的 ALBH 测站原始数据，保留原样。
- `data/README.md`：数据来源与说明。
